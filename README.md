# 🎮 KillStreak.tv Revival
### Bringing KillStreak.tv Back to Life!
**An unofficial, community-driven revival of KillStreak.tv, the multiplayer arena shooter.**
Discord: https://discord.gg/sPj4NBpSAv

KillStreak.tv was a fast-paced multiplayer shooter developed by SideQuestNZ and published by Blue Wizard Digital.
After the original online services were discontinued, the game became inaccessible to players who wanted to experience it again.
This project aims to restore the game's functionality, rebuild its multiplayer community, and preserve KillStreak.tv for future players.

## 🛠️ What We've Restored

### ✅ Photon Networking
The original Photon Cloud application is no longer available.
We've configured the game to use a new Photon application, allowing us to investigate restoring its original multiplayer functionality.

### ✅ Replacement Login System
The original FreeGames.io login service is no longer operational.
We've enabled the game's existing mock account system to allow it to load without contacting the discontinued account servers.

### ✅ Local Match Hosting
The original game depended on hosted match servers.
We've modified the networking configuration to enable the game's built-in match-hosting functionality.
This has successfully allowed gameplay to start again!
